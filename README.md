# Nodeproject
Dit is mijn node.js project. Dit bevat gewoon artikelen die kunnen gemaakt worden door een admin. Deze admin kan ook nieuwe categoriën aanmaken.

# Instalatiegids
Na het installeren begin je best met de database op te zetten. Er staat een .sql file onder de database folder waar u de tabbellen enzo kunt importeren.
Dit gaat gemakkelijk aan de hand van phpmyadmin

Daarna voert u gewoon de volgende commands uit
~~~
npm install
node index.js
~~~
Thats it. Nu runt de applicatie op poort :3000.
Je kunt gewoon gaan naar http://localhost:3000/
